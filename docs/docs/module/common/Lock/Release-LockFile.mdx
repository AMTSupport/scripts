## SYNOPSIS

Releases a lock file handle and removes the lock file.

## SYNTAX

```powershell
Release-LockFile [[-LockHandle] <IDisposable>] [[-LockPath] <String>]
```

## DESCRIPTION

Safely closes the handle and deletes the lock file.
Handles nulls and missing files.
