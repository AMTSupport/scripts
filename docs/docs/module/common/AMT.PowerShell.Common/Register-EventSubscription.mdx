## SYNOPSIS
Subscribe a script block to a registered event type, returning the subscription GUID.

## SYNTAX
```powershell
Register-EventSubscription [-EventType] <Type> -Callback <ScriptBlock> [-Priority <Priority>] [<CommonParameters>]
```

## DESCRIPTION
The event type must have been registered with Register-Event before subscribing. Callbacks are invoked in  order (High before Normal before Low); within the same priority, dispatch order is deterministic by subscription GUID.

## EXAMPLES

### Example 1

Subscribes to MyEvent and stores the GUID for later removal.

```powershell
$id = Register-EventSubscription -EventType ([MyEvent]) -Callback { param($e) Write-Host $e }
```
