## SYNOPSIS
Returns identifying metadata for the AMT.PowerShell.Common binary module.

## SYNTAX
```powershell
Get-AMTModuleInfo [<CommonParameters>]
```

## DESCRIPTION
Emits a single ModuleInfo object containing the module name, assembly version, and a short description.

## EXAMPLES

### Example 1

Returns the name, version, and description of the loaded AMT.PowerShell.Common module.

```powershell
Get-AMTModuleInfo
```
