## SYNOPSIS
Waits for one or more AsyncTaskRun or Task objects to complete and emits their results.

## SYNTAX
```powershell
Wait-Task [-Run] <Object> [-PassThru] [<CommonParameters>]
```

## DESCRIPTION
Collects all piped run objects in ProcessRecord, then blocks in EndProcessing until each completes. By default emits the result value; with PassThru emits the original run or Task object. Also available as the alias await.

## EXAMPLES

### Example 1

Starts an async task and waits for the result, returning "hello".

```powershell
async { 'hello' } | await
```


### Example 2

Waits for the task and emits the original AsyncTaskRun object.

```powershell
Start-AsyncTask { 'data' } | Wait-Task -PassThru
```
