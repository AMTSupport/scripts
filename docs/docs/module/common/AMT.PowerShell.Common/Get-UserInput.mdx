## SYNOPSIS
Prompts the user for free-form text input and returns the validated value.

## SYNTAX
```powershell
Get-UserInput [-AllowEmpty] [-AsSecureString] [-DontSaveInputs] -Question <String> [-SaveInputAsUniqueHistory] -Title <String> [-Validate <ScriptBlock>] [<CommonParameters>]
```

## DESCRIPTION
Re-prompts until the entered value passes optional  validation and is non-empty (unless  is set). When  is set the value is returned as a  and not persisted to history.

## EXAMPLES

### Example 1

Prompts for a non-empty name and validates it against the supplied script block.

```powershell
$name = Get-UserInput -Title 'Setup' -Question 'Enter your name:' -Validate { $_ -match '\w+' }
```
