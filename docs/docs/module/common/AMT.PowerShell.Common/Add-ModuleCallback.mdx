## SYNOPSIS
Registers a ScriptBlock to be invoked when a module is removed from the session.

## SYNTAX
```powershell
Add-ModuleCallback [-ScriptBlock] <ScriptBlock> [[-Module] <PSModuleInfo>] [<CommonParameters>]
```

## DESCRIPTION
The target module is resolved from the PowerShell call stack when -Module is omitted, so this cmdlet must be called from within module-level code. Throws a terminating error if no module context can be resolved.

## EXAMPLES

### Example 1

Registers a cleanup handler for the calling module.

```powershell
Add-ModuleCallback -ScriptBlock { Write-Host "Module unloaded" }
```
