## SYNOPSIS
Downloads and installs a PowerShell module from a GitHub repository archive.

## SYNTAX
```powershell
Install-ModuleFromGitHub -Branch <String> -GitHubRepo <String> [-Scope <String>] [<CommonParameters>]
```

## DESCRIPTION
Fetches the branch's zip archive from GitHub, extracts the module, copies it into the appropriate PowerShell modules directory, and returns the installed module name. Requires internet access.

## EXAMPLES

### Example 1

Installs the module for the current user from the main branch.

```powershell
Install-ModuleFromGitHub -GitHubRepo 'org/repo' -Branch 'main'
```


### Example 2

Installs the module for all users (requires elevation).

```powershell
Install-ModuleFromGitHub -GitHubRepo 'org/repo' -Branch 'main' -Scope AllUsers
```
