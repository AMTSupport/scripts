## SYNOPSIS
Releases a lock file handle and removes the lock file from disk.

## SYNTAX
```powershell
Release-LockFile [[-LockHandle] <IDisposable>] [[-LockPath] <String>] [<CommonParameters>]
```

## DESCRIPTION
Safely closes the  and deletes the file at . Both parameters are optional; null values are handled gracefully. Prefer Invoke-UnderLock for automatic acquisition and release.

## EXAMPLES

### Example 1

Closes the handle and deletes the lock file.

```powershell
Release-LockFile -LockHandle $handle -LockPath $lockPath
```
