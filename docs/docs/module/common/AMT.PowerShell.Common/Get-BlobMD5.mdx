## SYNOPSIS
Retrieve the Content-MD5 header value for an Azure Blob Storage resource.

## SYNTAX
```powershell
Get-BlobMD5 [-BlobUri] <String> [<CommonParameters>]
```

## DESCRIPTION
Issues an HTTP HEAD request to BlobUri and returns the Content-MD5 response header as a base64-encoded string. Returns  when the header is absent. Use the result with Find-FileByHash to check whether a blob is already cached locally.

## EXAMPLES

### Example 1

Returns the base64-encoded MD5 of the blob, or nothing if the header is missing.

```powershell
$md5 = Get-BlobMD5 -BlobUri "https://account.blob.core.windows.net/c/file.png?$qs"
```
