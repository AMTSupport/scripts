## SYNOPSIS
Runs all registered exit handlers for the current runspace.

## SYNTAX
```powershell
Invoke-Handlers [-IsFailure] [<CommonParameters>]
```

## DESCRIPTION
Iterates every handler registered via Register-ExitHandler. Handlers marked OnlyFailure are skipped unless  is set. Debug and warning messages produced by handlers are forwarded to the calling stream.

## EXAMPLES

### Example 1

Runs all exit handlers, including those registered with

-OnlyFailure

.

```powershell
Invoke-Handlers -IsFailure
```

## PARAMETERS
