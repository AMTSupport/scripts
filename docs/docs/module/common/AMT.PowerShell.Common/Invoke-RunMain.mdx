## SYNOPSIS
Run a script's main entry-point block with lifecycle management, restart support, and exit-code handling.

## SYNTAX
```powershell
Invoke-RunMain [-Cmdlet] <PSCmdlet> [-Main] <ScriptBlock> [-HideDisclaimer] [-NotStrict] [<CommonParameters>]
```

## DESCRIPTION
Applies Set-StrictMode -Version 3 and prints a legal disclaimer before invoking , unless suppressed via  or . Handles the QuickExit, FailedExit, and RestartScript control-flow error signals, and always invokes registered exit handlers when the run loop terminates. Bound parameters from the calling  are splatted onto .

## EXAMPLES

### Example 1

Runs the script block as the script entry point with strict mode and the disclaimer enabled.

```powershell
Invoke-RunMain -Cmdlet $PSCmdlet -Main { Write-Host 'Hello' }
```
