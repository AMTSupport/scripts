## SYNOPSIS
Iterates a collection with a progress bar, invoking a scriptblock for each item.

## SYNTAX
```powershell
Invoke-Progress [-Activity <String>] [-FailedProcessItem <ScriptBlock>] [-Format <ScriptBlock>] -Get <ScriptBlock> [-Id <Int32>] -Process <ScriptBlock> [-Status <String>] [<CommonParameters>]
```

## DESCRIPTION
Items are retrieved via the Get scriptblock, then each item is passed to Process. Progress is reported as a percentage; the bar is completed and dismissed when all items finish. If an item throws, FailedProcessItem is called when provided; otherwise the item is collected and a warning is emitted after the loop.

## EXAMPLES

### Example 1

Removes each file under C:\ with a live progress bar.

```powershell
Invoke-Progress -Get { Get-ChildItem C:\ } -Process { param($f) Remove-Item $f -Force }
```
