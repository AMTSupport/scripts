## SYNOPSIS
Runs exit handlers and terminates the pipeline with a success exit code.

## SYNTAX
```powershell
Invoke-QuickExit [<CommonParameters>]
```

## DESCRIPTION
Executes all registered exit handlers (non-failure mode) and then throws a terminating error with the identifier QuickExit. Use this when a script should stop cleanly without indicating a failure condition.

## EXAMPLES

### Example 1

Runs all non-failure exit handlers then terminates the pipeline immediately.

```powershell
Invoke-QuickExit
```
