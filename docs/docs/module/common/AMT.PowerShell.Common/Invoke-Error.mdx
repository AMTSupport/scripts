## SYNOPSIS
Writes a message to the host at the Error level, or throws a terminating error.

## SYNTAX
### InputObject

```powershell
Invoke-Error [[-InputObject] <Hashtable>] [-Caller <InvocationInfo>] [-CallerCmdlet <PSCmdlet>] [-ErrorCategory <ErrorCategory>] [-PassThru] [-Throw] [<CommonParameters>]
```

### Splat

```powershell
Invoke-Error [-Message] <String> [[-UnicodePrefix] <String>] [-Caller <InvocationInfo>] [-CallerCmdlet <PSCmdlet>] [-ErrorCategory <ErrorCategory>] [-PassThru] [-Throw] [<CommonParameters>]
```

### (All)

```powershell
Invoke-Error [-Caller <InvocationInfo>] [-CallerCmdlet <PSCmdlet>] [-ErrorCategory <ErrorCategory>] [-PassThru] [-Throw] [<CommonParameters>]
```

## DESCRIPTION
When -Throw is set the message is wrapped in an  and passed to ThrowTerminatingError. Otherwise the message is suppressed when $ErrorActionPreference is SilentlyContinue or Ignore.

## EXAMPLES

### Example 1

Throws a terminating error with the ObjectNotFound category.

```powershell
Invoke-Error -Message "File not found" -Throw -ErrorCategory ObjectNotFound
```
