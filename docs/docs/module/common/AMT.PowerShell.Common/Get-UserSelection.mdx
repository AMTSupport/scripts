## SYNOPSIS
Presents a list of choices to the user and returns the selected item.

## SYNTAX
```powershell
Get-UserSelection [-AllowNone] -Choices <Object[]> [-DefaultChoice <Int32>] [-FormatChoice <ScriptBlock>] -Question <String> -Title <String> [<CommonParameters>]
```

## DESCRIPTION
Formats each choice using  before display. If the user submits an empty response on the first attempt,  is returned. When  is set and the user cancels, $null is written; otherwise cancellation throws .

## EXAMPLES

### Example 1

Prompts the user to pick an operating system version.

```powershell
$selected = Get-UserSelection -Title 'OS' -Question 'Pick a version:' -Choices @('Win10','Win11')
```
