## SYNOPSIS
Runs exit handlers and terminates the pipeline with a non-zero exit code.

## SYNTAX
```powershell
Invoke-FailedExit [-ExitCode] <Int32> [-DontExit] [-ErrorRecord <ErrorRecord>] [-FormatArgs <String[]>] [<CommonParameters>]
```

## DESCRIPTION
Looks up the registered description for  and writes it as an error display message. If an  is supplied the deepest exception message is also shown. All registered exit handlers are executed before the terminating error is thrown. Pass  to suppress the terminating error (useful in tests).

## EXAMPLES

### Example 1

Displays the description registered for exit code 1, runs all exit handlers,
            then throws a terminating error carrying exit code 1.

```powershell
Invoke-FailedExit -ExitCode 1 -ErrorRecord $err
```
