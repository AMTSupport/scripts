## SYNOPSIS
Returns  if a registry value exists,  otherwise.

## SYNTAX
```powershell
Test-RegistryKey [-Path] <String> [-Key] <String> [<CommonParameters>]
```

## DESCRIPTION
Returns  if the registry path itself does not exist. Only supported on Windows.

## EXAMPLES

### Example 1

Returns $true if the Enabled value is present under HKLM:\SOFTWARE\MyApp.

```powershell
Test-RegistryKey -Path 'HKLM:\SOFTWARE\MyApp' -Key 'Enabled'
```
