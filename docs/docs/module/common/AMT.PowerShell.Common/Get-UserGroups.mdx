## SYNOPSIS
Gets the groups that a local user belongs to via the ADSI WinNT provider.

## SYNTAX
```powershell
Get-UserGroups [-User] <Object> [<CommonParameters>]
```

## DESCRIPTION
Returns one GroupObject per group the user is a direct member of. Only works on Windows via the WinNT ADSI provider.

## EXAMPLES

### Example 1

Returns all groups the local user localadmin belongs to.

```powershell
Get-UserGroups -User 'localadmin'
```


### Example 2

Pipes the localadmin user and returns its group memberships.

```powershell
Get-User -Name 'localadmin' | Get-UserGroups
```
