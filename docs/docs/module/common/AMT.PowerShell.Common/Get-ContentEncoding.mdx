## SYNOPSIS
Detects the text encoding of a file or byte array by inspecting its BOM.

## SYNTAX
### Bytes

```powershell
Get-ContentEncoding -ContentBytes <Byte[]> [<CommonParameters>]
```

### Path

```powershell
Get-ContentEncoding -Path <String> [<CommonParameters>]
```

## DESCRIPTION
Reads up to the first four bytes of the input to identify a byte-order mark. Falls back to UTF-8 when no recognised BOM is present.

## EXAMPLES

### Example 1

Returns the Encoding detected from the file's BOM.

```powershell
Get-ContentEncoding -Path 'C:\file.txt'
```


### Example 2

Returns the Encoding detected from the leading bytes.

```powershell
Get-ContentEncoding -ContentBytes $bytes
```
