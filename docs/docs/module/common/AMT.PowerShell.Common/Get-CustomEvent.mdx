## SYNOPSIS
Retrieve one or all registered custom event registrations from the event store.

## SYNTAX
```powershell
Get-CustomEvent [[-EventType] <Type>] [<CommonParameters>]
```

## DESCRIPTION
Without , returns the full registration dictionary (a  keyed by , mirroring the legacy $Script:Events variable) as a single un-enumerated object. With , returns the matching , or nothing if that type has not been registered.

## EXAMPLES

### Example 1

Returns the EventRegistration for MyEvent, or nothing if unregistered.

```powershell
Get-CustomEvent -EventType ([MyEvent])
```


### Example 2

Returns the entire event-store dictionary.

```powershell
Get-CustomEvent
```
