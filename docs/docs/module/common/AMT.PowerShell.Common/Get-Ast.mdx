## SYNOPSIS
Returns the PowerShell AST for a script block, script file path, or existing Ast node.

## SYNTAX
```powershell
Get-Ast -InputObject <Object> [<CommonParameters>]
```

## DESCRIPTION
Accepts a ScriptBlock, a file path string, or an existing Ast node. Returns nothing when the input cannot be parsed as a script.

## EXAMPLES

### Example 1

Returns the ScriptBlockAst for the given script block.

```powershell
Get-Ast -InputObject { param($x) $x }
```
