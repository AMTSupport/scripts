## SYNOPSIS
Forces a W32TM time resynchronisation if the last sync exceeds the threshold age.

## SYNTAX
```powershell
Sync-Time [-Threshold <TimeSpan>] [<CommonParameters>]
```

## DESCRIPTION
Checks the age of the last successful sync via Get-LastSyncTime. Returns  when a resync was triggered and succeeded, when the existing sync time is within the threshold. Windows-only; requires the w32tm service to be running.

## EXAMPLES

### Example 1

Resyncs the clock if the last sync was more than 7 days ago.

```powershell
Sync-Time
```


### Example 2

Resyncs the clock if the last sync was more than 1 hour ago.

```powershell
Sync-Time -Threshold ([TimeSpan]::FromHours(1))
```

## PARAMETERS

### -Threshold

Maximum allowed age of the last sync before a resync is triggered; defaults to 7 days.
