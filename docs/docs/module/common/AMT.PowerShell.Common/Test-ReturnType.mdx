## SYNOPSIS
Tests whether a script block's inferred return types are all within the allowed set.

## SYNTAX
```powershell
Test-ReturnType [-AllowNull] -InputObject <Object> -ValidTypes <Type[]> [<CommonParameters>]
```

## DESCRIPTION
Returns  when every inferred return type is contained in ValidTypes, otherwise . When AllowNull is specified, void/null returns do not cause a failure.

## EXAMPLES

### Example 1

Returns $true because the script block returns string.

```powershell
Test-ReturnType -InputObject { 'hello' } -ValidTypes ([string])
```


### Example 2

Returns $true because null is allowed.

```powershell
Test-ReturnType -InputObject { $null } -ValidTypes ([string]) -AllowNull
```
