## SYNOPSIS
Formats one or more ADSI user principals as hashtables containing Name and Domain.

## SYNTAX
```powershell
Format-ADSIUser [-User] <AdsiPrincipal[]> [<CommonParameters>]
```

## DESCRIPTION
Each input AdsiPrincipal must have a SchemaClassName of "User". The returned hashtable contains the keys "Name" and "Domain" split from the ADSI path.

## EXAMPLES

### Example 1

Formats all local users as Name/Domain hashtables.

```powershell
Get-User | Format-ADSIUser
```


### Example 2

Formats the localadmin user as a Name/Domain hashtable.

```powershell
Format-ADSIUser -User (Get-User -Name 'localadmin')
```
