## SYNOPSIS
Return the names of all blobs in an Azure Blob Storage container.

## SYNTAX
```powershell
Get-BlobList [-ContainerUrl] <String> [-SasQueryString] <String> [<CommonParameters>]
```

## DESCRIPTION
Issues paginated comp=list requests against the container, following NextMarker tokens until all pages are retrieved. Each blob name is emitted individually to the pipeline.

## EXAMPLES

### Example 1

Returns the names of every blob in the container.

```powershell
Get-BlobList -ContainerUrl 'https://account.blob.core.windows.net/fonts' -SasQueryString $qs
```
