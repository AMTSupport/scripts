## SYNOPSIS
Tests whether the current operating system is Windows 11 or later.

## SYNTAX
```powershell
Test-IsWindows11 [<CommonParameters>]
```

## DESCRIPTION
Returns  on non-Windows platforms without throwing. Detects Windows 11 by OS description string or build number >= 22000.

## EXAMPLES

### Example 1

Returns $true when running on Windows 11 or later.

```powershell
Test-IsWindows11
```
