## SYNOPSIS
Tests whether any network interface with internet connectivity is available.

## SYNTAX
```powershell
Test-NetworkConnection [<CommonParameters>]
```

## DESCRIPTION
Inspects local network interfaces for an operational adapter that is internet-capable. Returns  when such an interface exists, otherwise .

## EXAMPLES

### Example 1

Returns $true if at least one internet-capable network interface is up.

```powershell
Test-NetworkConnection
```
