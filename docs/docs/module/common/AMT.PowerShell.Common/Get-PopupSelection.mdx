## SYNOPSIS
Presents a GUI popup list and returns the item(s) the user selects.

## SYNTAX
```powershell
Get-PopupSelection [-AllowMultiple] [-AllowNone] -Items <Object[]> [-Title <String>] [<CommonParameters>]
```

## DESCRIPTION
Loops until a valid selection is made or  permits an empty result. When  is set, all selected items are enumerated to the pipeline. When  is set and nothing is selected, writes $null.

## EXAMPLES

### Example 1

Displays a popup list of drivers and returns the one the user picks.

```powershell
$choice = Get-PopupSelection -Title 'Pick a driver' -Items $drivers
```
