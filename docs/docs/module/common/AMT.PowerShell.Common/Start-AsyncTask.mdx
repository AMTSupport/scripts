## SYNOPSIS
Starts a PowerShell script block asynchronously and returns an AsyncTaskRun token.

## SYNTAX
```powershell
Start-AsyncTask [-ScriptBlock] <ScriptBlock> [-InputObject <Object>] [<CommonParameters>]
```

## DESCRIPTION
Launches the script in a new PowerShell runspace using BeginInvoke. The returned AsyncTaskRun can be passed to Wait-Task to collect the result. Also available as the alias async.

## EXAMPLES

### Example 1

Starts the script asynchronously and stores the run token.

```powershell
$run = Start-AsyncTask { Start-Sleep 5; 'done' }
```


### Example 2

Same as above using the async alias.

```powershell
$run = async { Get-ChildItem C:\ -Recurse }
```
