## SYNOPSIS
Infers the .NET return types of a PowerShell script block or AST.

## SYNTAX
```powershell
Get-ReturnType -InputObject <Object> [<CommonParameters>]
```

## DESCRIPTION
Performs static analysis of the AST output pipeline to determine possible return types. Variable references in the script are resolved against the current session state.

## EXAMPLES

### Example 1

Returns typeof(string).

```powershell
Get-ReturnType -InputObject { [string]'hello' }
```
