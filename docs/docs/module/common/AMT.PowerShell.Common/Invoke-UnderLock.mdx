## SYNOPSIS
Acquires an exclusive file lock, executes a script block, then releases the lock.

## SYNTAX
```powershell
Invoke-UnderLock [-ResourceId] <String> [-ScriptBlock] <ScriptBlock> [[-ArgumentList] <Object[]>] [<CommonParameters>]
```

## DESCRIPTION
Derives the script name from the caller, builds the lock path, and waits for the lock before invoking . The lock is always released in a finally block, so it is safe even when the script block throws. Pipeline output from the script block is forwarded to the caller.

## EXAMPLES

### Example 1

Runs driver installation exclusively, preventing concurrent runs for the same resource.

```powershell
Invoke-UnderLock -ResourceId 'DellDrivers' -ScriptBlock { Install-DellDrivers }
```
