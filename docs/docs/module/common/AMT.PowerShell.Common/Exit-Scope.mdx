## SYNOPSIS
Pops the current scope from the runspace scope stack.

## SYNTAX
```powershell
Exit-Scope [-ReturnValue <Object>] [<CommonParameters>]
```

## DESCRIPTION
Stops the elapsed-time stopwatch for the scope. When $VerbosePreference is Continue, emits a formatted exit message showing the scope name, elapsed time, and optionally the return value.

## EXAMPLES

### Example 1

Closes the scope and logs the return value in verbose mode.

```powershell
function Invoke-MyFunction {
                Enter-Scope -Invocation $MyInvocation
                $result = Get-Something
                Exit-Scope -ReturnValue $result
                return $result
            }
```
