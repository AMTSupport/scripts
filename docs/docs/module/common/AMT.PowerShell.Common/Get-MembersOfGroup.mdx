## SYNOPSIS
Gets the members of a local group via the ADSI WinNT provider.

## SYNTAX
```powershell
Get-MembersOfGroup [-Group] <Object> [<CommonParameters>]
```

## DESCRIPTION
Enumerates all principals that are direct members of the specified group. Only works on Windows via the WinNT ADSI provider.

## EXAMPLES

### Example 1

Returns all members of the Administrators group.

```powershell
Get-MembersOfGroup -Group (Get-Group -Name 'Administrators')
```


### Example 2

Pipes the Administrators group and returns its members.

```powershell
Get-Group -Name 'Administrators' | Get-MembersOfGroup
```
