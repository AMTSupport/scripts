## SYNOPSIS
Establish authenticated connections to one or more Microsoft cloud services.

## SYNTAX
```powershell
Connect-Service [-Services] <String[]> [[-Scopes] <String[]>] [[-AccessToken] <SecureString>] [-CheckOnly] [-DontConfirm] [<CommonParameters>]
```

## DESCRIPTION
Iterates over each service in Services, resolving its ServiceDefinition from ConnectionRuntime. For each service the cmdlet:

1. Checks whether an existing connection is already present and optionally re-uses it, prompting for confirmation unless DontConfirm is set.

2. Disconnects and reconnects when the existing connection is missing required Scopes or when multiple services are connected under different accounts.

3. Verifies after connecting that all services share the same account identity when their definitions are marked as matchable.

When CheckOnly is set the cmdlet only verifies connectivity and throws a terminating error for any service that is not already connected.

## EXAMPLES

### Example 1

Connects to Exchange Online and Microsoft Graph, skipping the confirmation prompt.

```powershell
Connect-Service -Services ExchangeOnline, Graph -Scopes 'Mail.Read' -DontConfirm
```


### Example 2

Throws a terminating error when not already connected to Microsoft Graph.

```powershell
Connect-Service -Services Graph -CheckOnly
```
