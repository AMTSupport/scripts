## SYNOPSIS
Resolves a local user from an AdsiPrincipal object or a name string.

## SYNTAX
```powershell
Get-UserByInputOrName [-InputObject] <Object> [<CommonParameters>]
```

## DESCRIPTION
Accepts either an already-resolved AdsiPrincipal or a plain string user name. Useful as a normalisation step in pipeline-driven scripts. Only works on Windows via the WinNT ADSI provider.

## EXAMPLES

### Example 1

Resolves the local user localadmin by name.

```powershell
Get-UserByInputOrName -InputObject 'localadmin'
```


### Example 2

Returns the already-resolved AdsiPrincipal unchanged.

```powershell
Get-UserByInputOrName -InputObject (Get-User -Name 'localadmin')
```
