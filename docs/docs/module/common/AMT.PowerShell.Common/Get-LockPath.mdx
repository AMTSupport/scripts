## SYNOPSIS
Returns the full path to the lock file for the given resource and script.

## SYNTAX
```powershell
Get-LockPath [-ResourceId] <String> [[-ScriptName] <String>] [<CommonParameters>]
```

## DESCRIPTION
Builds a path of the form $TempPath\AMT_{ScriptName}_{ResourceId}.lock. When  is omitted, the name is derived from the caller's script file or command name via MyInvocation.

## EXAMPLES

### Example 1

Returns the lock file path for the

DellDrivers

resource in the current script.

```powershell
$lockPath = Get-LockPath -ResourceId 'DellDrivers'
```
