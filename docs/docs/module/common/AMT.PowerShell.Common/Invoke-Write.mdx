## SYNOPSIS
Writes a formatted, coloured message to the host or returns it as a string.

## SYNTAX
### InputObject

```powershell
Invoke-Write [[-InputObject] <Hashtable>] [<CommonParameters>]
```

### Splat

```powershell
Invoke-Write [-InformationTag <String>] [-MultiLineIndent <Int32>] -PSColour <String> -PSMessage <String> [-PSPrefix <String>] [-PassThru] [-ShouldWrite <Boolean>] [<CommonParameters>]
```

## DESCRIPTION
This is the low-level write helper used by all level-specific cmdlets. When ShouldWrite is false the call is a no-op. When PassThru is set the formatted string is returned to the pipeline instead. An optional InformationTag is attached when writing to the information stream.

## EXAMPLES

### Example 1

Writes "Done" in green to the console.

```powershell
Invoke-Write -PSMessage "Done" -PSColour "Green" -ShouldWrite $true
```


### Example 2

Returns the formatted string via the pipeline.

```powershell
Invoke-Write @{ PSMessage = "Hello"; PSColour = "Cyan"; PassThru = $true }
```
