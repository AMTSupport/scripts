## SYNOPSIS
Defines a read-only script variable whose value is computed lazily on first access.

## SYNTAX
```powershell
Set-LazyVariable [-Name] <String> [-Value] <ScriptBlock> [-PassThru] [<CommonParameters>]
```

## DESCRIPTION
The variable is set in the caller's local scope as read-only. The first time it is read, the Value script block executes and the result is memoised. Also available as the alias lazy.

## EXAMPLES

### Example 1

Creates a lazy $Config variable that loads the config file on first use.

```powershell
Set-LazyVariable -Name 'Config' -Value { Import-PowerShellDataFile 'config.psd1' }
```


### Example 2

Same as above using the lazy alias.

```powershell
lazy Config { Import-PowerShellDataFile 'config.psd1' }
```
