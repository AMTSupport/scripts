## SYNOPSIS
Adds a user to a local group via the ADSI WinNT provider.

## SYNTAX
```powershell
Add-MemberToGroup [-Group] <Object> [-User] <Object> [<CommonParameters>]
```

## DESCRIPTION
Returns  when the user was added, or  when the user was already a member. Only works on Windows via the WinNT ADSI provider.

## EXAMPLES

### Example 1

Adds the local user localadmin to the Administrators group.

```powershell
Add-MemberToGroup -Group (Get-Group -Name 'Administrators') -User 'localadmin'
```
