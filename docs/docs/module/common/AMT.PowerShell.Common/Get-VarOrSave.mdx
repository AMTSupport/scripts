## SYNOPSIS
Returns the cached value of a process environment variable, computing and saving it on first access.

## SYNTAX
```powershell
Get-VarOrSave -LazyValue <ScriptBlock> [-Validate <ScriptBlock>] -VariableName <String> [<CommonParameters>]
```

## DESCRIPTION
If the variable already exists and passes optional validation, its value is returned immediately. Otherwise the LazyValue script block is invoked, the result is stored in the environment variable, and the value is returned.

## EXAMPLES

### Example 1

Returns the value of MY_VAR, computing it via the script block on first call.

```powershell
Get-VarOrSave -VariableName 'MY_VAR' -LazyValue { 'computed' }
```


### Example 2

Recomputes MY_VAR if the existing value fails validation.

```powershell
Get-VarOrSave -VariableName 'MY_VAR' -LazyValue { Get-Thing } -Validate { $_ -ne $null }
```
