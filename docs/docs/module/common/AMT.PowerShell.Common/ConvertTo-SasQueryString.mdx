## SYNOPSIS
Parse a raw SAS token into a URL-encoded query string.

## SYNTAX
```powershell
ConvertTo-SasQueryString [-SasToken] <String> [<CommonParameters>]
```

## DESCRIPTION
Extracts key-value pairs from the token, URL-encodes the sig value, and reassembles them as an application/x-www-form-urlencoded query string suitable for appending to an Azure Blob Storage URL.

## EXAMPLES

### Example 1

Returns the parsed query string ready to append with

?

to a container URL.

```powershell
$qs = ConvertTo-SasQueryString -SasToken $env:BLOB_SAS_TOKEN
```


### Example 2

Accepts the token from the pipeline.

```powershell
$env:BLOB_SAS_TOKEN | ConvertTo-SasQueryString
```
