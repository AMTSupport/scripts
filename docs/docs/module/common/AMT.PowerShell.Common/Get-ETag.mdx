## SYNOPSIS
Computes an S3-compatible ETag for a local file using the specified chunk size.

## SYNTAX
```powershell
Get-ETag [-Path] <String> [-ChunkSize] <Int32> [<CommonParameters>]
```

## DESCRIPTION
Splits the file into chunks of ChunkSize bytes, hashes each chunk with MD5, then hashes the concatenated digests to produce a multi-part ETag of the form "hash-N".

## EXAMPLES

### Example 1

Returns the S3 ETag for the file using 8 MiB parts.

```powershell
Get-ETag -Path 'C:\file.bin' -ChunkSize 8388608
```
