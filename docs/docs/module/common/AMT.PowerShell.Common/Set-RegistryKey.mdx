## SYNOPSIS
Creates or updates a registry value, creating intermediate key nodes as needed.

## SYNTAX
```powershell
Set-RegistryKey [-Path] <String> [-Key] <String> [-Value] <Object> [-Kind] <RegistryValueKind> [-Confirm] [-WhatIf] [<CommonParameters>]
```

## DESCRIPTION
If the target value already exists it is updated in place; otherwise a new value is created with the specified type. All intermediate registry path segments are created if absent. Uses ShouldProcess to support -WhatIf and -Confirm. Only supported on Windows.

## EXAMPLES

### Example 1

Creates or updates the Enabled DWord value under HKLM:\SOFTWARE\MyApp.

```powershell
Set-RegistryKey -Path 'HKLM:\SOFTWARE\MyApp' -Key 'Enabled' -Value 1 -Kind DWord
```
