## SYNOPSIS
Writes a message to the host at the Warning level.

## SYNTAX
### InputObject

```powershell
Invoke-Warn [[-InputObject] <Hashtable>] [-PassThru] [<CommonParameters>]
```

### Splat

```powershell
Invoke-Warn [-Message] <String> [[-UnicodePrefix] <String>] [-PassThru] [<CommonParameters>]
```

### (All)

```powershell
Invoke-Warn [-PassThru] [<CommonParameters>]
```

## DESCRIPTION
Suppressed when $WarningPreference is SilentlyContinue or Ignore. Accepts either individual parameters (Splat set) or a pre-built hashtable (InputObject set).

## EXAMPLES

### Example 1

Writes the message in yellow with the warning prefix if WarningPreference allows it.

```powershell
Invoke-Warn -Message "Deprecated parameter used"
```
