## SYNOPSIS
Gets the timestamp of the last successful W32TM time synchronisation.

## SYNTAX
```powershell
Get-LastSyncTime [<CommonParameters>]
```

## DESCRIPTION
Calls w32tm /query /status and parses the "Last Successful Sync Time" field. Returns the Unix epoch (1970-01-01) when the query fails or no sync time is found. Windows-only; requires the w32tm service to be running.

## EXAMPLES

### Example 1

Returns the DateTime of the last successful Windows time synchronisation.

```powershell
Get-LastSyncTime
```
