## SYNOPSIS
Retrieve the parsed content of a named cache entry, invoking CreateBlock to populate it when missing or stale.

## SYNTAX
```powershell
Get-CachedContent [-Name] <String> -CreateBlock <ScriptBlock> [-IsValidBlock <ScriptBlock>] [-MaxAge <TimeSpan>] [-NoCache] [-ParseBlock <ScriptBlock>] [-WriteBlock <ScriptBlock>] [<CommonParameters>]
```

## DESCRIPTION
Resolves the cache file path via String), then validates the existing file against MaxAge, IsValidBlock, or NoCache. If the file is absent or invalid it is regenerated by calling CreateBlock.

Content is written as plain text via String) unless WriteBlock is supplied, which receives the cache path and raw content object.

The cached file is then read and passed to ParseBlock if supplied; otherwise it is parsed with ConvertFrom-Json -AsHashtable and the resulting object is emitted to the pipeline.

## EXAMPLES

### Example 1

Returns the parsed JSON hashtable, refreshing the cache when it is older than one hour.

```powershell
Get-CachedContent -Name 'config' -CreateBlock { Invoke-RestMethod 'https://api/config' | ConvertTo-Json } -MaxAge ([TimeSpan]::FromHours(1))
```
