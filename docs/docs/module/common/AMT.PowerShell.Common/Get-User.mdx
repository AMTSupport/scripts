## SYNOPSIS
Gets local user accounts from the ADSI WinNT provider.

## SYNTAX
```powershell
Get-User [[-Name] <String>] [<CommonParameters>]
```

## DESCRIPTION
Returns all local users when Name is omitted, or a single user by name. Only works on Windows via the WinNT ADSI provider.

## EXAMPLES

### Example 1

Returns every local user account.

```powershell
Get-User
```


### Example 2

Returns the local user named localadmin.

```powershell
Get-User -Name 'localadmin'
```
