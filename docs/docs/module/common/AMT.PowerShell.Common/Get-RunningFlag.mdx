## SYNOPSIS
Returns the well-known  that tracks whether the script is currently executing.

## SYNTAX
```powershell
Get-RunningFlag [<CommonParameters>]
```

## DESCRIPTION
The running flag is a specialised flag with a fixed context. Set it at script startup and clear it on exit to allow other processes to detect whether this script is active.

## EXAMPLES

### Example 1

Retrieves the running flag and marks the script as active.

```powershell
$running = Get-RunningFlag; $running.Set()
```
