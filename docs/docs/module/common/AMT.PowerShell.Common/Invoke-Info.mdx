## SYNOPSIS
Writes a message to the host at the Information level.

## SYNTAX
### InputObject

```powershell
Invoke-Info [[-InputObject] <Hashtable>] [-PassThru] [<CommonParameters>]
```

### Splat

```powershell
Invoke-Info [-Message] <String> [[-UnicodePrefix] <String>] [-PassThru] [<CommonParameters>]
```

### (All)

```powershell
Invoke-Info [-PassThru] [<CommonParameters>]
```

## DESCRIPTION
Suppressed when $InformationPreference is Ignore. Accepts either individual parameters (Splat set) or a pre-built hashtable (InputObject set).

## EXAMPLES

### Example 1

Writes the message in cyan with the info prefix if InformationPreference allows it.

```powershell
Invoke-Info -Message "Setup complete"
```
