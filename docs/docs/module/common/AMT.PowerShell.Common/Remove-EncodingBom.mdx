## SYNOPSIS
Strips the byte-order mark (BOM) from a byte array for the given encoding.

## SYNTAX
```powershell
Remove-EncodingBom [-Bytes] <Byte[]> [-Encoding] <Encoding> [<CommonParameters>]
```

## DESCRIPTION
Returns the input byte array unchanged when no BOM is present.

## EXAMPLES

### Example 1

Returns $bytes with the UTF-8 BOM removed if present.

```powershell
Remove-EncodingBom -Bytes $bytes -Encoding ([System.Text.Encoding]::UTF8)
```
