## SYNOPSIS
Terminate the pipeline if the current process is running elevated as Administrator.

## SYNTAX
```powershell
Invoke-EnsureUser [<CommonParameters>]
```

## DESCRIPTION
Windows-only; on non-Windows platforms the check is silently skipped. Counterpart to Invoke-EnsureAdministrator: use this where a script must not run elevated. A  or  from the P/Invoke elevation query is treated as an indeterminate soft-pass.

## EXAMPLES

### Example 1

Throws a terminating PermissionDenied error when the session is elevated.

```powershell
Invoke-EnsureUser
```
