## SYNOPSIS
Formats an  or  into human-readable diagnostic rows.

## SYNTAX
### ErrorRecord

```powershell
Format-Error -ErrorRecord <Object> [-Message <String>] [-PassThru] [-PreviewExtraLines <Int32>] [-UnicodePrefix <String>] [<CommonParameters>]
```

### InvocationInfo

```powershell
Format-Error -InvocationInfo <InvocationInfo> [-Message <String>] [-PassThru] [-PreviewExtraLines <Int32>] [-UnicodePrefix <String>] [<CommonParameters>]
```

### (All)

```powershell
Format-Error [-Message <String>] [-PassThru] [-PreviewExtraLines <Int32>] [-UnicodePrefix <String>] [<CommonParameters>]
```

## DESCRIPTION
Produces labelled rows for File, Where, Preview, and Message. When PassThru is set the rows are returned as strings instead of written to the information stream.

## EXAMPLES

### Example 1

Writes formatted diagnostic rows for the current invocation.

```powershell
Format-Error -InvocationInfo $MyInvocation -Message "Unexpected state"
```
