## SYNOPSIS
Tests whether the current process is running as the NT AUTHORITY\SYSTEM account.

## SYNTAX
```powershell
Test-IsRunningAsSystem [<CommonParameters>]
```

## DESCRIPTION
Returns  on non-Windows platforms without throwing.

## EXAMPLES

### Example 1

Returns $true when the PowerShell host is running as SYSTEM.

```powershell
Test-IsRunningAsSystem
```
