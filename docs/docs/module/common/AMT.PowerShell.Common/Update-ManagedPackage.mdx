## SYNOPSIS
Updates a package to its latest version using the detected system package manager.

## SYNTAX
```powershell
Update-ManagedPackage [-PackageName] <String> [-Confirm] [-WhatIf] [<CommonParameters>]
```

## DESCRIPTION
Detects the available package manager (e.g., Chocolatey, Winget) and updates the named package. Uses ShouldProcess to support -WhatIf and -Confirm. Writes a non-terminating error if the update fails.

## EXAMPLES

### Example 1

Updates the git package to its latest available version.

```powershell
Update-ManagedPackage -PackageName 'git'
```
