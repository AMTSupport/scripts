## SYNOPSIS
Returns the absolute file-system path for a flag identified by context name.

## SYNTAX
```powershell
Get-FlagPath [-Context] <String> [<CommonParameters>]
```

## DESCRIPTION
Delegates path resolution to FlagPathResolver; the returned string can be used directly with file-system cmdlets or passed to lower-level flag operations.

## EXAMPLES

### Example 1

Returns the full path to the flag file for context

SoftwareInstalled

.

```powershell
$path = Get-FlagPath -Context 'SoftwareInstalled'
```
