## SYNOPSIS
Returns the PSStyle ANSI foreground escape sequence for a given  value.

## SYNTAX
```powershell
Get-ConsoleColour [-Colour] <ConsoleColor> [<CommonParameters>]
```

## DESCRIPTION
Maps  enum members to the corresponding $PSStyle.Foreground.* string so callers can embed colour sequences in strings without depending on the PSStyle variable directly.

## EXAMPLES

### Example 1

Returns the ANSI foreground escape sequence for red.

```powershell
$red = Get-ConsoleColour -Colour Red
```
