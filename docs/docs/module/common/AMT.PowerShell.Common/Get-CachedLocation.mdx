## SYNOPSIS
Resolve the filesystem path of a named cache file, invoking CreateBlock to populate it when missing or stale.

## SYNTAX
```powershell
Get-CachedLocation [-Name] <String> -CreateBlock <ScriptBlock> [-IsValidBlock <ScriptBlock>] [-MaxAge <TimeSpan>] [-NoCache] [-WriteBlock <ScriptBlock>] [<CommonParameters>]
```

## DESCRIPTION
Derives the cache file path from Name using String) and validates the existing file against MaxAge, IsValidBlock, or NoCache. When the file is absent or invalid it is recreated by calling CreateBlock.

Content is written as plain text via String) unless WriteBlock is supplied, which receives the cache path and raw content object as arguments.

The resolved cache file path is emitted to the pipeline regardless of whether the file was freshly created or already existed.

## EXAMPLES

### Example 1

Returns the path to the cached file, downloading the blob only when needed.

```powershell
Get-CachedLocation -Name 'wallpaper' -CreateBlock { Download-Blob } -WriteBlock { param($p,$c) [IO.File]::WriteAllBytes($p,$c) }
```
