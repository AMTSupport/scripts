## SYNOPSIS
Returns the path to a named temporary folder, creating it if necessary.

## SYNTAX
```powershell
Get-NamedTempFolder [-Name] <String> [-ForceEmpty] [<CommonParameters>]
```

## DESCRIPTION
The folder is created under the system temp directory using the supplied name as a subdirectory. The folder persists between calls unless -ForceEmpty is specified, which clears its contents before returning the path.

## EXAMPLES

### Example 1

Returns (or creates) a stable temp folder named MyScript.

```powershell
$dir = Get-NamedTempFolder -Name 'MyScript'
```


### Example 2

Returns the MyScript temp folder after removing any existing contents.

```powershell
$dir = Get-NamedTempFolder -Name 'MyScript' -ForceEmpty
```
