## SYNOPSIS
Registers .NET types as PowerShell type accelerators and auto-removes them when the module unloads.

## SYNTAX
```powershell
Export-Types [-Types] <Type[]> [[-Module] <PSModuleInfo>] [-Clobber] [<CommonParameters>]
```

## DESCRIPTION
Each type's FullName is used as the accelerator key. A cleanup callback is registered via Add-ModuleCallback so accelerators are removed when the owning module is removed from the session. Throws a terminating error if an accelerator key is already claimed by another module, unless -Clobber is set.

## EXAMPLES

### Example 1

Registers both types as accelerators scoped to the calling module.

```powershell
Export-Types -Types ([MyNamespace.MyClass], [MyNamespace.OtherClass])
```
