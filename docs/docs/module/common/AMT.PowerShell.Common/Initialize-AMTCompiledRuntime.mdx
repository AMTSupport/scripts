## SYNOPSIS
Extracts embedded modules and prepares a private PSModulePath for a compiled script runtime.

## SYNTAX
```powershell
Initialize-AMTCompiledRuntime [-EmbeddedModules] <Hashtable[]> [-PrivateModuleRoot <String>] [<CommonParameters>]
```

## DESCRIPTION
Iterates the EmbeddedModules descriptors produced by the AMT compiler, extracts each into a content-addressed folder under the private module root, and prepends that root to PSModulePath. Returns a RuntimeState object describing the original and updated module paths. Intended for use by compiled script templates; not for interactive use.

## EXAMPLES

### Example 1

Extracts the embedded modules into the default private root and updates PSModulePath.

```powershell
Initialize-AMTCompiledRuntime -EmbeddedModules $embeddedModules
```
