## SYNOPSIS
Tests whether a package is installed via the detected package manager.

## SYNTAX
```powershell
Test-ManagedPackage [-PackageName] <String> [<CommonParameters>]
```

## DESCRIPTION
Detects the available package manager and queries it for the named package. Returns  if the package is installed,  otherwise.

## EXAMPLES

### Example 1

Returns $true if git is installed, $false otherwise.

```powershell
Test-ManagedPackage -PackageName 'git'
```
