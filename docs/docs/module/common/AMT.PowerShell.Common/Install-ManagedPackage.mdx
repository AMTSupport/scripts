## SYNOPSIS
Installs a package using the detected system package manager.

## SYNTAX
```powershell
Install-ManagedPackage [-PackageName] <String> [-Confirm] [-NoFail] [-Sha256 <String>] [-WhatIf] [<CommonParameters>]
```

## DESCRIPTION
Detects the available package manager (e.g., Chocolatey, Winget) and installs the named package. Uses ShouldProcess to support -WhatIf and -Confirm. Terminates on failure unless -NoFail is specified.

## EXAMPLES

### Example 1

Installs the git package using the available package manager.

```powershell
Install-ManagedPackage -PackageName 'git'
```


### Example 2

Installs Notepad++ with SHA256 verification; writes a non-terminating error on failure.

```powershell
Install-ManagedPackage -PackageName 'notepadplusplus' -Sha256 'abc123...' -NoFail
```
