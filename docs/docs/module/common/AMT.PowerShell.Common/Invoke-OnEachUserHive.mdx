## SYNOPSIS
Runs a script block against each local user's registry hive.

## SYNTAX
```powershell
Invoke-OnEachUserHive [-ScriptBlock] <ScriptBlock> [<CommonParameters>]
```

## DESCRIPTION
Enumerates all user profiles under HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList (filtering to standard and AzureAD SIDs). For each profile, temporarily loads the ntuser.dat hive via reg.exe if it is not already mounted, invokes the script block, then unloads the hive if it was loaded by this cmdlet. The script block receives a PSObject with SID, UserHive, and Username properties. Only supported on Windows.

## EXAMPLES

### Example 1

Writes a DWord registry value to every loaded user hive.

```powershell
Invoke-OnEachUserHive -ScriptBlock {
                param($hive)
                Set-RegistryKey -Path "Registry::HKEY_USERS\$($hive.SID)\SOFTWARE\MyApp" -Key 'Setting' -Value '1' -Kind DWord
            }
```
