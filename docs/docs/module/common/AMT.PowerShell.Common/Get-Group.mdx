## SYNOPSIS
Gets local group accounts from the ADSI WinNT provider.

## SYNTAX
```powershell
Get-Group [[-Name] <String>] [<CommonParameters>]
```

## DESCRIPTION
Returns all local groups when Name is omitted, or a single group by name. Only works on Windows via the WinNT ADSI provider.

## EXAMPLES

### Example 1

Returns every local group account.

```powershell
Get-Group
```


### Example 2

Returns the local group named Administrators.

```powershell
Get-Group -Name 'Administrators'
```
