## SYNOPSIS
Compute the base64-encoded MD5 hash of a local file, matching Azure Blob Storage's Content-MD5 format.

## SYNTAX
```powershell
Get-BlobCompatableHash [-Path] <String> [<CommonParameters>]
```

## DESCRIPTION
Reads the file at Path as a byte array, computes its MD5 digest, and returns the result as a base64 string — the same representation Azure uses for the Content-MD5 response header. Use this to compare a local file against a blob's server-side hash without downloading the blob.

## EXAMPLES

### Example 1

Returns the base64-encoded MD5 hash of the file.

```powershell
$hash = Get-BlobCompatableHash -Path 'C:\Downloads\image.png'
```
