## SYNOPSIS
Returns a  instance for the specified context name.

## SYNTAX
```powershell
Get-Flag [-Context] <String> [<CommonParameters>]
```

## DESCRIPTION
A flag is a persistent on-disk marker used to track whether a particular operation has already been performed. The returned object exposes methods to test, set, and clear the flag.

## EXAMPLES

### Example 1

Retrieves a flag object for the context

SoftwareInstalled

.

```powershell
$flag = Get-Flag -Context 'SoftwareInstalled'
```
