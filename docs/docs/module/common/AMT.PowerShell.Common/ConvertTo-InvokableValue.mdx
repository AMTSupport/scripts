## SYNOPSIS
Converts a value to a PowerShell-invokable string representation.

## SYNTAX
```powershell
ConvertTo-InvokableValue -Value <Object> [<CommonParameters>]
```

## DESCRIPTION
Null, strings, numbers, booleans, and PSObjects are each serialised to a canonical form that can be embedded in a script and re-evaluated.

## EXAMPLES

### Example 1

Returns the string "42".

```powershell
ConvertTo-InvokableValue -Value 42
```


### Example 2

Returns the string "$null".

```powershell
ConvertTo-InvokableValue -Value $null
```
