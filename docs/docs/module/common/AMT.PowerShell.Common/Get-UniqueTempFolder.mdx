## SYNOPSIS
Creates and returns a new uniquely-named temporary folder under the system temp directory.

## SYNTAX
```powershell
Get-UniqueTempFolder [<CommonParameters>]
```

## DESCRIPTION
Each call generates a distinct folder path using a random or GUID-based name. The caller is responsible for cleaning up the folder when finished. Use Invoke-WithinEphemeral for automatic cleanup.

## EXAMPLES

### Example 1

Creates a new unique temp folder and returns its full path.

```powershell
$dir = Get-UniqueTempFolder
```
