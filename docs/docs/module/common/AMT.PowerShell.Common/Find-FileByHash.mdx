## SYNOPSIS
Search a directory for a file whose blob-compatible MD5 hash matches the given value.

## SYNTAX
```powershell
Find-FileByHash [-Hash] <String> [-Path] <String> [-Filter <String>] [<CommonParameters>]
```

## DESCRIPTION
Iterates over files in Path that match Filter, computes the base64-encoded MD5 hash of each using , and returns the full path of the first file whose hash equals Hash. Returns nothing (no pipeline output) when no matching file is found.

## EXAMPLES

### Example 1

Returns the full path of the first PNG in

C:\Cache

whose hash matches

$md5

.

```powershell
Find-FileByHash -Hash $md5 -Path 'C:\Cache' -Filter '*.png'
```
