## SYNOPSIS
Terminate the pipeline if the current process is not running elevated as Administrator.

## SYNTAX
```powershell
Invoke-EnsureAdministrator [<CommonParameters>]
```

## DESCRIPTION
Windows-only; on non-Windows platforms the check is silently skipped. Uses a P/Invoke call to query token elevation, so a  or is treated as an indeterminate soft-pass.

## EXAMPLES

### Example 1

Throws a terminating PermissionDenied error when the session is not elevated.

```powershell
Invoke-EnsureAdministrator
```
