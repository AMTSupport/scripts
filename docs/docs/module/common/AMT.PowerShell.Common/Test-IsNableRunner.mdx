## SYNOPSIS
Return  when the current session is hosted inside the N-able fmplugin.exe process.

## SYNTAX
```powershell
Test-IsNableRunner [<CommonParameters>]
```

## DESCRIPTION
Inspects the console window-title leaf and compares it case-insensitively to fmplugin.exe. Use this to suppress UI-heavy output paths that do not render correctly inside the N-able runner.

## EXAMPLES

### Example 1

Conditionally adjusts output based on the detected host environment.

```powershell
if (Test-IsNableRunner) { Write-Host 'Running under N-able' }
```
