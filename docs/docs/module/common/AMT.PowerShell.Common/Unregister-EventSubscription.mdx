## SYNOPSIS
Remove a subscription from a registered event, returning  if it was found and removed.

## SYNTAX
```powershell
Unregister-EventSubscription -EventType <Type> -Id <Guid> [<CommonParameters>]
```

## DESCRIPTION
Returns  when the event type is not registered, or no subscription with the given GUID exists. Idempotent — calling with an already-removed  returns without error.

## EXAMPLES

### Example 1

Removes the subscription identified by $subscriptionId from the MyEvent registration.

```powershell
Unregister-EventSubscription -EventType ([MyEvent]) -Id $subscriptionId
```
