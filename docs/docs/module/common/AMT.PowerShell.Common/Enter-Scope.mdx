## SYNOPSIS
Pushes the caller's invocation onto the runspace scope stack.

## SYNTAX
```powershell
Enter-Scope [-ArgumentFormatter <Hashtable>] [-IgnoreParams <String[]>] [-Invocation <InvocationInfo>] [-PassThru] [<CommonParameters>]
```

## DESCRIPTION
Records the caller's  and starts an elapsed-time stopwatch for the scope. When $VerbosePreference is Continue, emits a formatted entry message showing the scope name and bound parameters. Pair with Exit-Scope to close the scope.

## EXAMPLES

### Example 1

Wraps a function body in a named, timed scope.

```powershell
function Invoke-MyFunction {
                Enter-Scope -Invocation $MyInvocation
                # ... work ...
                Exit-Scope
            }
```
