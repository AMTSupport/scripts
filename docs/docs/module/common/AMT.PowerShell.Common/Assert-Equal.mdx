## SYNOPSIS
Assert that two objects are equal, throwing a terminating error if they differ.

## SYNTAX
```powershell
Assert-Equal [-Object] <Object> [-Expected] <Object> [-Message <String>] [<CommonParameters>]
```

## DESCRIPTION
Compares Object and Expected using . When they are not equal a terminating  is written with the error ID AMT.Assert.Equal. An optional custom message overrides the default Object [{0}] does not equal expected value [{1}] template.

## EXAMPLES

### Example 1

Throws a terminating error when

$result

is not equal to

'expected-value'

.

```powershell
Assert-Equal -Object $result -Expected 'expected-value'
```


### Example 2

Passes silently because the pipeline value matches the expected value.

```powershell
'actual' | Assert-Equal -Expected 'actual'
```
