## SYNOPSIS
Dispatch an event instance to all subscribers registered for its runtime type.

## SYNTAX
```powershell
Submit-Event -EventInstance <Object> [<CommonParameters>]
```

## DESCRIPTION
The runtime type of  determines which EventRegistration is looked up. wrappers are unwrapped before dispatch. Silently no-ops when no registration exists for the type.

## EXAMPLES

### Example 1

Dispatches a MyEvent instance to all currently registered subscribers.

```powershell
Submit-Event -EventInstance ([MyEvent]::new('payload'))
```
