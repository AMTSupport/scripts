## SYNOPSIS
Removes a user from a local group via the ADSI WinNT provider.

## SYNTAX
```powershell
Remove-MemberFromGroup [-Group] <Object> [-Member] <Object> [<CommonParameters>]
```

## DESCRIPTION
Returns  when the user was removed, or  when the user was not a member of the group. Only works on Windows via the WinNT ADSI provider.

## EXAMPLES

### Example 1

Removes the local user localadmin from the Administrators group.

```powershell
Remove-MemberFromGroup -Group (Get-Group -Name 'Administrators') -Member 'localadmin'
```
