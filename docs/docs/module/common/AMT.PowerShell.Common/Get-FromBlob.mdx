## SYNOPSIS
Download a blob from Azure Blob Storage to a local cache directory, returning the local file path.

## SYNTAX
### ByDirectUrl

```powershell
Get-FromBlob [-Url] <String> -CachePath <String> -SasToken <String> [<CommonParameters>]
```

### ByUrlAndPath

```powershell
Get-FromBlob [-BaseURL] <String> [-BlobPath] <String> -CachePath <String> -SasToken <String> [<CommonParameters>]
```

### (All)

```powershell
Get-FromBlob -CachePath <String> -SasToken <String> [<CommonParameters>]
```

## DESCRIPTION
Checks the cache before downloading: computes the blob's Content-MD5 via Get-BlobMD5 and searches CachePath for an existing file with a matching hash using Find-FileByHash. Returns the existing path without re-downloading when a match is found.

When no cached copy exists the blob is downloaded to a randomly-named .png file inside CachePath and that path is returned.

Two parameter sets are supported: ByDirectUrl (a fully-qualified blob URL) and ByUrlAndPath (a container base URL combined with a relative blob path).

## EXAMPLES

### Example 1

Downloads the blob if not already cached, returns the local file path.

```powershell
Get-FromBlob -Url 'https://account.blob.core.windows.net/c/image.png' -CachePath 'C:\Cache' -SasToken $token
```


### Example 2

Constructs the blob URL from base URL and path, then downloads or returns from cache.

```powershell
Get-FromBlob -BaseURL 'https://account.blob.core.windows.net/fonts' -BlobPath 'Arial.ttf' -CachePath 'C:\Cache' -SasToken $token
```
