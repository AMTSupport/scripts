## SYNOPSIS
Tests whether all parameters in a script block are declared with types from the allowed set.

## SYNTAX
```powershell
Test-Parameters -InputObject <Object> -ValidTypes <String[]> [<CommonParameters>]
```

## DESCRIPTION
Statically analyses the param block of the input script to verify that every parameter type name is present in ValidTypes.

## EXAMPLES

### Example 1

Returns $true because the parameter is typed as string.

```powershell
Test-Parameters -InputObject { param([string]$x) } -ValidTypes 'string'
```
