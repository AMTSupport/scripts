## SYNOPSIS
Runs exit handlers and signals the host to restart the current script.

## SYNTAX
```powershell
Restart-Script [<CommonParameters>]
```

## DESCRIPTION
Executes all registered exit handlers (non-failure mode), writes an informational restart message, then throws a terminating error with identifier RestartScript. The calling harness is responsible for catching this error and re-launching the script.

## EXAMPLES

### Example 1

Runs all non-failure exit handlers then signals a restart.

```powershell
Restart-Script
```
