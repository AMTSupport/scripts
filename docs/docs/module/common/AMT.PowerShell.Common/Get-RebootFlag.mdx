## SYNOPSIS
Returns the well-known  that tracks whether a reboot is pending.

## SYNTAX
```powershell
Get-RebootFlag [<CommonParameters>]
```

## DESCRIPTION
The reboot flag is a specialised flag with a fixed context. It is set when a component requests a system reboot and cleared after the reboot completes.

## EXAMPLES

### Example 1

Checks whether a reboot is pending and restarts the computer if so.

```powershell
$reboot = Get-RebootFlag; if ($reboot.IsSet) { Restart-Computer }
```
