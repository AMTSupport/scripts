## SYNOPSIS
Prompts the user with a Yes/No question and returns the boolean answer.

## SYNTAX
```powershell
Get-UserConfirmation [-DefaultChoice <Boolean>] -Question <String> -Title <String> [<CommonParameters>]
```

## DESCRIPTION
Presents a selection prompt with Yes and No choices. If the user enters an empty string on the first attempt, the  is used. Invalid input causes the prompt to repeat. Cancelling throws .

## EXAMPLES

### Example 1

Asks the user to confirm, defaulting to No.

```powershell
$confirmed = Get-UserConfirmation -Title 'Delete files' -Question 'Are you sure?' -DefaultChoice $false
```
