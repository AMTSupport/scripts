## SYNOPSIS
Registers a script block to run when the script exits.

## SYNTAX
```powershell
Register-ExitHandler [-Name] <String> [-ExitHandler] <ScriptBlock> [-OnlyFailure] [<CommonParameters>]
```

## DESCRIPTION
Handlers are stored per-runspace and executed in registration order by Invoke-Handlers and Invoke-FailedExit. Re-registering a handler with the same name overwrites the previous entry with a warning. Use  to restrict a handler to failure exits only.

## EXAMPLES

### Example 1

Registers a cleanup handler that runs on every exit.

```powershell
Register-ExitHandler -Name 'Cleanup' -ExitHandler { Remove-Item $tempDir -Recurse }
```
