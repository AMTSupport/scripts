## SYNOPSIS
Removes a registry value if it exists.

## SYNTAX
```powershell
Remove-RegistryKey [-Path] <String> [-Key] <String> [-Confirm] [-WhatIf] [<CommonParameters>]
```

## DESCRIPTION
No-ops silently if the registry path or the named value does not exist. Uses ShouldProcess to support -WhatIf and -Confirm. Only supported on Windows.

## EXAMPLES

### Example 1

Deletes the OldSetting value from HKLM:\SOFTWARE\MyApp.

```powershell
Remove-RegistryKey -Path 'HKLM:\SOFTWARE\MyApp' -Key 'OldSetting'
```
