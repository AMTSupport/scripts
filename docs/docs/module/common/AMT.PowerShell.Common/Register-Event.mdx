## SYNOPSIS
Register a CLR type as a dispatchable event in the event store.

## SYNTAX
```powershell
Register-Event [-EventType] <Type> [<CommonParameters>]
```

## DESCRIPTION
Creates an empty  for the given type. Must be called before Register-EventSubscription or Submit-Event can be used with that type.

## EXAMPLES

### Example 1

Registers MyEvent so that subscriptions and dispatches can target it.

```powershell
Register-Event -EventType ([MyEvent])
```
