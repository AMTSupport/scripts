## SYNOPSIS
Adds a lazily-evaluated script property to a PSObject.

## SYNTAX
```powershell
Add-LazyProperty [-Name] <String> [-Value] <ScriptBlock> -InputObject <PSObject> [-PassThru] [<CommonParameters>]
```

## DESCRIPTION
The script block is only executed the first time the property is accessed. Subsequent reads return the memoised value stored as a NoteProperty.

## EXAMPLES

### Example 1

Attaches a lazy Hash property that computes on first access.

```powershell
$obj | Add-LazyProperty -Name 'Hash' -Value { Get-FileHash $this.Path }
```


### Example 2

Same as above, returning the modified PSObject.

```powershell
$obj | Add-LazyProperty -Name 'Hash' -Value { Get-FileHash $this.Path } -PassThru
```
