## SYNOPSIS
Compares a local file's computed hash to an S3 ETag to verify integrity.

## SYNTAX
```powershell
Compare-FileHashToS3ETag [-Path] <String> [-ETag] <String> [<CommonParameters>]
```

## DESCRIPTION
Supports both single-part (MD5) and multi-part ETags. Returns  when the computed hash matches the ETag.

## EXAMPLES

### Example 1

Returns $true if the file's computed hash matches the ETag.

```powershell
Compare-FileHashToS3ETag -Path 'C:\file.bin' -ETag '"abc123"'
```
