## SYNOPSIS
Displays a countdown progress bar for a fixed duration, then invokes a callback.

## SYNTAX
```powershell
Invoke-Timeout -Activity <String> [-AllowCancel] [-CancelScript <ScriptBlock>] -StatusMessage <String> -Timeout <Int32> [-TimeoutScript <ScriptBlock>] [<CommonParameters>]
```

## DESCRIPTION
The progress bar ticks approximately every 50 ms. If -AllowCancel is set and a key is pressed before the timeout elapses, CancelScript is invoked instead of TimeoutScript.

## EXAMPLES

### Example 1

Counts down 10 seconds, then restarts the computer.

```powershell
Invoke-Timeout -Timeout 10 -Activity "Waiting" -StatusMessage "{0}s remaining" -TimeoutScript { Restart-Computer }
```
