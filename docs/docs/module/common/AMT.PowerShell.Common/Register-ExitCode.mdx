## SYNOPSIS
Registers a human-readable description for a new exit code and returns the assigned code.

## SYNTAX
```powershell
Register-ExitCode [-Description] <String> [<CommonParameters>]
```

## DESCRIPTION
Each call allocates the next sequential exit code for the current runspace and stores the supplied description. The description is later retrieved by Invoke-FailedExit to display a meaningful message. Exit codes are runspace-scoped and not shared across sessions.

## EXAMPLES

### Example 1

Registers the description and assigns an integer exit code, returned to

$exitCode

.

```powershell
$exitCode = Register-ExitCode -Description 'Network connection failed'
```
