## SYNOPSIS
Assert that the input object is not null, throwing a terminating error if it is.

## SYNTAX
```powershell
Assert-NotNull [[-Object] <Object>] [-Message <String>] [<CommonParameters>]
```

## DESCRIPTION
Checks Object using . When the value is null a terminating  is written with the error ID AMT.Assert.NotNull. An optional custom message overrides the default An unexpected null value was encountered. text.

## EXAMPLES

### Example 1

Throws a terminating error when

$value

is null.

```powershell
Assert-NotNull -Object $value
```


### Example 2

Passes silently when

$service

is non-null; emits the custom message otherwise.

```powershell
$service | Assert-NotNull -Message 'Service must not be null.'
```
