## SYNOPSIS
Uninstalls a package using the detected system package manager.

## SYNTAX
```powershell
Uninstall-ManagedPackage [-PackageName] <String> [-Confirm] [-NoFail] [-WhatIf] [<CommonParameters>]
```

## DESCRIPTION
Detects the available package manager (e.g., Chocolatey, Winget) and removes the named package. Uses ShouldProcess to support -WhatIf and -Confirm. Terminates on failure unless -NoFail is specified.

## EXAMPLES

### Example 1

Uninstalls the git package using the available package manager.

```powershell
Uninstall-ManagedPackage -PackageName 'git'
```


### Example 2

Attempts uninstallation and writes a non-terminating error if it fails.

```powershell
Uninstall-ManagedPackage -PackageName 'notepadplusplus' -NoFail
```
