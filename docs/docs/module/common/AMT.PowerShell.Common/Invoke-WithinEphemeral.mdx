## SYNOPSIS
Runs a script block inside a newly created ephemeral temporary folder.

## SYNTAX
```powershell
Invoke-WithinEphemeral [-ScriptBlock] <ScriptBlock> [<CommonParameters>]
```

## DESCRIPTION
Creates a unique temp folder, sets it as the working directory, invokes the script block, then restores the original location and deletes the folder (best-effort) on completion regardless of whether the script block throws.

## EXAMPLES

### Example 1

Downloads and extracts a file into a temp folder that is deleted afterwards.

```powershell
Invoke-WithinEphemeral -ScriptBlock {
                Invoke-WebRequest 'https://example.com/archive.zip' -OutFile 'archive.zip'
                Expand-Archive 'archive.zip' -DestinationPath '.'
            }
```
