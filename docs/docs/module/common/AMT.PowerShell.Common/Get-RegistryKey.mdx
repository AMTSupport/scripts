## SYNOPSIS
Retrieves the value of a registry property at the specified path.

## SYNTAX
```powershell
Get-RegistryKey [-Path] <String> [-Key] <String> [<CommonParameters>]
```

## DESCRIPTION
Returns  if the registry path does not exist or the named value is not present under that path. Only supported on Windows.

## EXAMPLES

### Example 1

Reads the Version value from HKLM:\SOFTWARE\MyApp.

```powershell
Get-RegistryKey -Path 'HKLM:\SOFTWARE\MyApp' -Key 'Version'
```
