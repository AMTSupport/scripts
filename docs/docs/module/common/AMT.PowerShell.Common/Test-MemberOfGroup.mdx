## SYNOPSIS
Tests whether a user is a member of a local group via the ADSI WinNT provider.

## SYNTAX
```powershell
Test-MemberOfGroup [-Group] <Object> [-User] <Object> [<CommonParameters>]
```

## DESCRIPTION
Returns  when the user is a direct member of the group, otherwise . Only works on Windows via the WinNT ADSI provider.

## EXAMPLES

### Example 1

Returns $true if localadmin is a member of the Administrators group.

```powershell
Test-MemberOfGroup -Group (Get-Group -Name 'Administrators') -User 'localadmin'
```
