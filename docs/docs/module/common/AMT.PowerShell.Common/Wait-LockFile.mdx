## SYNOPSIS
Waits for and acquires an exclusive write lock on the specified lock file path.

## SYNTAX
```powershell
Wait-LockFile [-LockPath] <String> [[-LockOwner] <String>] [<CommonParameters>]
```

## DESCRIPTION
Polls until the lock is available, up to a 600-second timeout. Writes process metadata (PID, optional owner, timestamp) into the lock file. Returns the open  handle; pass it to Release-LockFile when done.

## EXAMPLES

### Example 1

Acquires the lock and returns the file handle.

```powershell
$handle = Wait-LockFile -LockPath $lockPath -LockOwner 'DellDrivers'
```
