## SYNOPSIS
Returns the formatted display name for the current top-of-stack scope.

## SYNTAX
```powershell
Format-ScopeName [-IsExit] [<CommonParameters>]
```

## DESCRIPTION
Delegates to  for the current runspace. The formatted name reflects entry or exit style depending on -IsExit.

## EXAMPLES

### Example 1

Returns the entry-style name of the innermost scope.

```powershell
Format-ScopeName
```


### Example 2

Returns the exit-style name of the innermost scope.

```powershell
Format-ScopeName -IsExit
```

## PARAMETERS

### -IsExit
