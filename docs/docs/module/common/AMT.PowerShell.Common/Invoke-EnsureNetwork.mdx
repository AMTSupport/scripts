## SYNOPSIS
Verify an internet connection is available, optionally connecting to a named Wi-Fi network.

## SYNTAX
```powershell
Invoke-EnsureNetwork [-Name <String>] [-Password <SecureString>] [<CommonParameters>]
```

## DESCRIPTION
Pings 8.8.8.8 to test reachability. If no connection exists and  is supplied, uses netsh wlan to add and connect a WPA2-PSK (or open) profile, then polls for up to 60 seconds. Outputs  when a connection was established by this invocation, when one was already present. Throws a terminating ConnectionError if no network can be reached. The Wi-Fi connect path is Windows-only.

## EXAMPLES

### Example 1

Passes silently when already connected; throws if no network is available.

```powershell
Invoke-EnsureNetwork
```


### Example 2

Attempts to connect to the Corp-WiFi SSID using the supplied password before asserting connectivity.

```powershell
Invoke-EnsureNetwork -Name 'Corp-WiFi' -Password $securePassword
```
